# PDF-XChange 取字连续圈注（ClickCircle 1.8.6）

原生 `.pvp` 入口 + C# 工具，在便携版 PDF-XChange Editor 10.8.4 / 11.0.1 x64 中加载运行；使用编辑器标准的 `/Circle` 椭圆标注与自带撤销、保存流程。详细测试记录见 `VALIDATION.md`；新会话接手本项目先读 `AGENTS.md`（项目规则、构建/测试/发布/真机验证流程）。

## 功能

- **取文字**：单击图纸上的编号（例如 `LI-282`）取样，这次点击不生成标注，主题写入面板并可手动修改。测量标注/文字批注的标签（例如图纸上绿色的 `300X200 EAD`、`400X200 EAD` 尺寸标签，这类文字不在页面文字层里）也能点到取到，按标注 Contents 还原成屏幕上看到的标签文字。取字状态会保持，可以继续单击取下一个编号，片段按面板“分隔符”累积拼成一个主题；取完按右键完成取字，进入连续圈注。取字过程中再按快捷键或再点“取文字”会清空已取片段和主题，重新从第一段开始。
- **取字提示**：单击或框选取字成功后，鼠标右下方会弹出一个小提示，显示“已取 N 段 · 内容”，约 0.8 秒后自动消失；提示半透明（88% 不透明度），靠近屏幕边缘时自动翻到鼠标另一侧，不抢焦点、不挡鼠标点击。
- **框选取文字**：仍在“取字”状态时按住左键拖出一个矩形，松开后按视觉顺序取矩形内所有文字段：行从上到下、行内从左到右，用面板“分隔符”拼接成主题。框选结果同样并入当前取字、不结束取字，可继续单击或框选追加，右键完成。
- **AutoCAD SHX 取字**：支持从作者标记为 `AutoCAD SHX Text` 的专用批注读取原文和位置；单击优先取原生文字，未命中再取 SHX。框选可混合原生文字和 SHX，继续使用同一套排序与分隔符；不同位置的重复编号保留，同位置完全相同的原生文字段优先保留，避免重复加入。
- **区域 OCR 与校对**：点“区域识别”后拖框，或普通框选没有找到原文时，渲染框内原图并打开校对窗口；设置页“区域识别 → 识别后显示校对窗”可以关掉，关掉后识别完直接把结果并入主题或圈注（不弹窗、也不进校对）。本地识别后可以逐行修改、增删文字片段，合并主题实时预览；点“确认并圈注”才把结果填入主题并进入连续圈注（取字过程中自动进入的识别会并入当前主题，右键再完成取字）。识别和校对本身不生成标注，取消保留原主题。
- **分隔符**：预设 `/`、`-`、`，`、`、`、`空格`、`无分隔符`，也可直接输入任意字符串；改动后已取到的多段文字立即重组，手动改过主题后不再自动重组。
- **主题历史**：面板底部列出用过的主题，带搜索框与固定（星标）列，点某一行即可把它取回主题并继续标注；最近 50 个主题、最多固定 50 个，固定项排在前面。右键完成取字、成功放圈或显式确认校对结果时记入历史；取字过程中累积的中间主题不记入。设置页“主题历史 → 显示主题历史”可以关掉：关掉后历史区隐藏、面板收成紧凑高度（客户区 480×190）、不再记录新主题；重新打开恢复原高度并继续记录。
- **连续圈注**：每次点击以鼠标位置为中心放一个椭圆，新椭圆自动保持选中（带缩放手柄与旋转柄），右侧属性面板立即显示它的主题、颜色、尺寸和不透明度；继续点击则选中转到最新的那个。按下左键时即使移动了鼠标（拖动或手抖），松开也会在松开处放圈，不必“原地不动”；取字状态下的拖动仍然用于框选。默认纸面尺寸 1.5 × 1.2 mm，可在面板改宽高（只影响后续标注，自动记忆）。填充 RGB 239/83/80，边框 RGB 211/47/47、实线 0.2 pt，不透明度 60%。主题写入标注 Subject，页面不额外绘制文字。
- **快捷键**：默认 `Ctrl+Alt+P`，等同点“取文字”，可改成任意组合键甚至单键（例如 `F9`、`A`）。只在本编辑器是前台窗口时响应；焦点在面板输入框、编辑器查找框、另存为等对话框、标注文字编辑区时一律不拦截，其他程序更不受影响。不再要求页面画布此刻持有输入焦点，因此取字途中、圈注途中按快捷键都能立刻生效，不会“按了没反应”。实现只用低级键盘钩子（`WH_KEYBOARD_LL`），不再注册全局热键；钩子装不上时面板状态行会给出原因，快捷键不可用而其他功能照常。被忽略时日志写 `Hotkey ignored: <原因>`，触发时写 `Hotkey fired (mode=…)`。
- **鼠标光标**：取字状态用文本光标（I 形），去点图纸上的编号；框选与连续圈注用十字光标，方便对准位置。切换状态时光标立即变化，不必先移动鼠标；按住左键拖框期间始终是十字。
- **标注样式自动套用（1.8.0）**：设置页 →“编辑样式…”打开样式对话框，可对新标注自动写入：
  - 字段：主题、作者、标签/正文（留空表示不修改原有值）；
  - 样式：线条颜色、填充颜色（可开关）、边框宽度、不透明度、虚线边框；
  - 测量：比例尺（1 mm = X m）、小数位、千位分隔符。
  范围可选“只套用到测量标注（周长/面积/线）”或“所有新标注”。绘制方式不变——继续用编辑器自带的周长/面积/矩形/椭圆等工具画，插件在标注创建后自动套用样式，因此多点测量的原生交互完全保留。实现上监听文档的 `e.annots.inserted` 事件，对新增标注写入数据后立即生效，不依赖固定工具、也不需要改动绘制流程。样式默认关闭，关闭时行为与之前版本完全一致。
- **版本号**：面板标题显示当前版本（例如“取字连续圈注 v1.8.6”）；启动时日志同时写入 `Version 1.8.6`，方便确认实际加载的版本。
- **面板布局**：主页只保留主题、四个操作按钮、状态条和主题历史；分隔符、圈注尺寸、快捷键和“检查更新”收进设置页（状态条右侧“设置”进入，左上角“返回主页面”退出）。状态条用圆点颜色区分暂停/取字/标注，快捷键、当前尺寸与分隔符在主页一眼可见。
- **在线更新**：面板状态行右侧的“检查更新”按钮读取 GitHub 仓库 `main` 分支的 `version.txt`（不受 API 限流；读取失败才回退到 tags API），发现新版本时弹窗确认。确认后先检查所有文档是否已保存，再把三个发行文件下载到临时目录，交由一个独立批处理等待编辑器退出、备份旧文件、替换并在失败时回滚，最后自动重启编辑器。下载走公开的 `raw.githubusercontent.com`，不需要 GitHub 账号或令牌。检查结果（正在检查 / 已是最新 / 失败原因）显示在设置页底部的提示行，不占用主页状态行。
- **面板可缩放**：拖窗口边缘即可改变大小，主题历史表格跟着长高变宽，放大后一次能看到更多主题；最小尺寸保证各行控件都露出来（客户区不小于 440 × 380；关掉主题历史后为 440 × 190）。大小在松手时记入 `settings.xml`，重开面板按上次大小恢复。
- **排版随字号自适应**：行高按当前字体与控件首选高度计算，150% 缩放下不再把字挤进固定行高；主题、分隔符、宽高、快捷键四行的标签列统一到同一宽度，输入框左边缘对齐；宽高数字框固定 96 像素、分隔符下拉框 150 像素，右边留白，不再被拉伸成通栏；表格行高与表头高度跟随字号。
- **右键完成**：取字时右键完成取字、带着累积主题进入连续圈注；连续圈注（“继续标注”状态）时右键完成本次标注，已画的椭圆与主题都保留，点“继续标注”可以接着放圈。两次右键都会吞掉紧随的那次右键菜单，不再弹出编辑器的页面右键菜单；完成标注时工具与光标稍后（约 0.3 秒，等这次右键消息走完）交回编辑器，状态行显示“已完成标注，可继续标注”。`Esc` 仍是放弃。
- **暂停与撤销**：`Esc` 或面板“暂停”放弃本次取字并停止；取字时右键完成取字、进入圈注，圈注时右键完成本次标注，“继续标注”恢复；切换文档自动暂停；每次撤销只移除一个椭圆，保存重开后仍是可编辑标注。
- **取字来源**：普通“取文字”优先直接读文字层和 SHX 原文；无原文的框选自动进入 OCR。已有原文但内容错误、乱码或漏字时，可主动点“区域识别”强制识别原图，不混入不完整的原文结果。

## 使用

1. 保存正在编辑的 PDF，正常退出并重开编辑器，让它加载插件。
2. 点顶部快速访问工具栏的“取字连续圈注”按钮打开面板。
3. 点“取文字”（或按快捷键），依次单击图纸上的编号；也可以拖框一次取矩形内多段文字。每次取字只写入主题、不产生椭圆，多次单击/框选的结果按“分隔符”拼接；面板状态行显示已取几段。取完按右键完成取字。
4. 取字完成后，每次左键点击页面都在点击处放一个椭圆，新圈注保持选中，属性面板同步显示它；要换主题再点“取文字”。选中状态不打断连续标注，`Esc` 暂停时照常退出。
5. 按 `Esc` 或“暂停”停止（取字尚未右键完成时按 `Esc` 放弃本次取字）；连续圈注时也可以右键完成本次标注；点“继续标注”用当前主题继续。
6. 改快捷键：点状态条右侧“设置”进入设置页，点“操作快捷键”那一行，变成“请按新的组合键…”后直接按下想用的键立即生效；`Backspace`/`Delete` 或“清除”取消绑定；`Esc` 放弃本次录入；左上角“返回主页面”回到主页。
7. 用编辑器的撤销、保存、标注属性处理这些椭圆。插件不会自动保存 PDF。
8. 面板底部“主题历史”列出用过的主题：在搜索框里输入关键字过滤，点主题那一行（或选中后按 `Enter`）把它取回主题并继续标注；勾“固定”列的勾选框把常用主题置顶，固定超过 50 个时状态行会提示。
9. 扫描图或没有原文的矢量图：点“区域识别”并拖框，等待本地识别后对照左侧原图校对右侧文字；右侧每一行作为一个片段，空行忽略，按面板分隔符合并。确认后继续点击页面放圈。需要识别中文说明时，选择已安装的中文语言，再点“重新识别”；方向不正时可点旋转按钮，旋转原图并重新识别。
10. 需要升级时点“设置”页底部的“检查更新”：发现新版本会弹窗确认，确认后自动检查未保存文档、下载三个文件、关闭编辑器、替换并重启；有未保存文档时会取消本次更新。

设置保存在 `settings.xml`：`WidthMm`、`HeightMm`、`PickHotkey`（`None` 表示不注册）、`Separator`、`OcrLanguage`（上次选用的识别语言）、`ShowOcrReview`（区域识别后是否弹校对窗，默认 `true`）、`ShowHistory`（是否显示/记录主题历史，默认 `true`）、`SubjectHistory`（主题历史与固定项）、`PanelWidth`/`PanelHeight`（面板客户区大小）。

### SHX 选择边界

SHX 专用批注只给出整段原文与整段矩形，没有逐字位置。因此单击取得整段；框选以整段矩形中心是否进入选框为准，蓝色预览显示整段矩形，不能截取半个 SHX 编号。原生文字仍按字符中心选取，可以选半截文字。编号内部的 `/`、`-`、空格等保持原样，分隔符只加在取得的片段之间。

SHX 矩形坐标会先归一化，再交给编辑器转换，适用于倒置矩形、原生页面旋转和临时视图旋转。重叠的 SHX 范围单击优先取较小范围，再比较距中心的距离；可偏开重叠处单击，或框选后手动调整主题。普通作者的批注内容不参与取字。

### 区域 OCR 范围

- 使用本机 Windows `Windows.Media.Ocr`，不上传图纸，不写入或改造 PDF 文字层。需要 Windows PowerShell 5.1 和至少一个已安装的 Windows OCR 语言。系统缺少组件、脚本被系统策略阻止、语言不可用或识别超时时，显示错误并保留原主题；插件不安装系统语言，也不修改系统策略。
- “自动（编号优先）”比较最多八个已安装语言引擎的结果，优先英数编号；窗口状态显示实际选中的语言。它只是选择候选结果，不替换 `0/O`、`1/I`、标点或其他字符。中文等自然语言建议显式选对应语言识别。
- 相距较远的词拆成片段，相邻词保留空格，重复编号不去重。识别不保证工程编号准确，确认前应逐字核对；可以直接在校对框修改。确认过的片段继续支持更改分隔符时即时重组，手动改主题后依然退出自动重组。
- 按当前页面与临时视图方向渲染，区域最长边限制 2400 像素，避免整张大图造成过大内存占用；较小选区更容易识别。倾斜、复杂线条、极小字体或重叠字仍可能识别失败。
- 识别在后台执行，窗口可取消；切换文档、工具或卸载时作废任务及其结果。单次识别最长等待约 30 秒。只终止该次识别辅助进程，不结束编辑器。
- 辅助脚本嵌入 `ClickCircle.Core.dll`，运行时在唯一临时目录释放脚本和区域图片，结束后清理；发行安装仍只有原来的三个文件，不依赖 Python 或外部服务。

## 安装与卸载

本机插件目录（仓库 `CircleStampPlugin` 的上一级就是便携版根目录）：

```text
F:\桌面1\PDFEditor\Plugins.x64
```

发行文件为 `dist\ClickCircle.pvp`、`dist\ClickCircle.Core.dll`、`dist\PDFXEdit.dll`，三者必须同目录。安装就是把这三个文件复制进 `Plugins.x64`：先退出编辑器，复制，再重开。

简化脚本（Windows 批处理，双击即可，不需要改 PowerShell 执行策略）：

```bat
install.cmd                        # 安装/升级，先把旧文件备份到 output\install-backup-<时间>
install.cmd "D:\...\PDF Editor"    # 脚本放在别处时指定编辑器目录
uninstall.cmd                      # 卸载，只删三个插件文件，保留设置、日志和 PDF
uninstall.cmd "D:\...\PDF Editor"  # 同上，显式指定编辑器目录
```

脚本不结束编辑器进程：检测到目标编辑器正在运行就直接提示退出，不做任何改动；复制后逐字节校验，失败会报错。卸载前也会把三个文件备份到 `output\uninstall-backup-<时间>`。

升级前保存 PDF 并正常关闭目标编辑器，双击 `install.cmd`，再重开编辑器；面板标题和 `plugin.log` 里的 `Version` 行可用于确认版本。最新安装与验证状态见 `VALIDATION.md`。

## 从源码构建

只用 Windows 自带的 .NET Framework 4.x x64 编译器与 IL 汇编器，不需要 Visual Studio，也不需要注册 COM：互操作程序集直接从目标编辑器的 `PXCEditorCore.x64.dll` 内嵌类型库生成。

```powershell
.\build.ps1 -RunTests
.\build.ps1 -EditorDirectory 'C:\...\PDF Editor' -OutputDirectory '.\my-dist' -RunTests
```

编辑器的 `PXCEditorCore.x64.dll` 才内嵌类型库；本机便携版目录只有 `PDFXEditCore.x64.dll`，此时 `build.ps1` 会报缺少依赖，可沿用 `VALIDATION.md` 记录的备用编译方式：用系统 `csc.exe`/`ilasm.exe`，把现成的 `dist\PDFXEdit.dll` 当互操作引用（`/codepage:65001`，资源 `tools\ocr-helper.ps1`），输出同样三个文件。

构建产物只复制上述三个文件到 `dist`。`src` 是插件代码：

| 文件 | 职责 |
| --- | --- |
| `Plugin.cs` | 插件生命周期、面板、设置、模式切换、页面点击与框选回调 |
| `CircleTool.cs` | 自定义页面工具：按下/移动/松开、框选高亮、页面坐标换算、椭圆写入 |
| `TextRegionPicker.cs` | 框选文字采集与按行分段 |
| `ShxTextReader.cs` | 只读识别 SHX 专用批注、归一化范围与单击命中 |
| `AnnotSelector.cs` | 把新建椭圆放进文档的注释选择集并设为当前选择，让手柄和属性面板跟住它 |
| `OcrRegionRenderer.cs` | 通过编辑器渲染选区原图，限制像素大小并处理显示旋转 |
| `OcrService.cs` | 本地识别辅助进程、取消和超时、结果协议与片段排序 |
| `OcrReviewDialog.cs` | 区域预览、语言选择、旋转重识别、文字校对与明确确认 |
| `StampPanel.cs` | 面板与设置（含分隔符、快捷键录入） |
| `ModeCursor.cs` | 各状态的鼠标光标常量：取字用文本光标，框选与放椭圆用十字光标 |
| `RightClickRouting.cs` | 右键路由：取字完成取字、圈注完成标注、区域识别与暂停不拦截右键；`ContextMenuGuard` 负责吞掉右键菜单并把“交回工具”延迟到菜单消息之后 |
| `LeftReleaseRouting.cs` | 左键松开手势：取字拖动是框选；其余状态（含圈注时按下左键后拖动过）一律按一次点击处理 |
| `AnnotationLabel.cs` | 把标注 Contents 还原成屏幕上可见的标签文字（测量标注的反斜杠分行、反序与末尾测量值） |
| `HotkeyBinding.cs` | 快捷键解析、显示、持久化 |
| `HotkeyScope.cs` | 触发范围判定（前台、模态、原生输入框、页面焦点） |
| `HotkeyService.cs` | 低级键盘钩子、按键去重、延时复核、隐藏消息窗口 |

`tools` 是类型库提取器、`.pvp` 引导入口和一次性面板预览工具；`obj`、`build-*` 是中间产物，`test-host` 是独立测试用编辑器副本，都不进发行包。

## 打包

```powershell
.\package.ps1                     # 默认 1.8.6
.\package.ps1 -Version 1.8.6      # 指定版本
```

按白名单打包三个发行文件、源码、脚本、说明、测试与样例，产出 `release\ClickCircle-<版本>-x64.zip`；同名包已存在时拒绝覆盖。可加 `-IncludeDrawingDemo` 把照明图演示 PDF 一起打进去。

## 校验

`tests\verify_output.py` 用 Python + `pypdf` 只读检查保存后的标注（数量、各页分布、主题、纸面尺寸、颜色、不透明度），结果以 JSON 输出：

```powershell
python .\tests\verify_output.py .\output\ClickCircle_acceptance_result.pdf --expect-count 9 --expect-page-counts 5 1 1 2 --subject-size CUSTOM-2x3 2 3
```

`--allow-size 3 2` 额外允许其他尺寸；`--subject-size 主题 宽 高` 按主题限定尺寸。

SHX 回归样例为 `tests\ClickCircle_shx_selection.pdf`：4 种旋转，包含只有矢量轮廓的 SHX 编号、重复编号、带空格与斜杠的文字、原生文字、同位置双重表示与应忽略的普通批注。`create_shx_fixture.py` 需要 `fonttools`、`reportlab`、`pypdf` 与 Windows Arial 字体，均为测试依赖，插件不依赖 Python 或外部识别服务。

`build.ps1 -RunTests` 运行 15 个测试程序共 945 项：TextPicker 34、HotkeyBinding 92、HotkeyPanel 35、HotkeyService 145、RegionPicker 71、SeparatorPanel 111、ShxText 91、OCR 142、HistoryPreference 82、Cursor 8、RightClick 21、LeftRelease 10、PanelSize 33、Update 31、AnnotStyle 39。还可在单独的编辑器副本中运行只读 SDK 验收：

```powershell
.\tests\run-shx-host-tests.ps1 -EditorDirectory 'C:\测试副本\PDF Editor' -DrawingPath 'C:\图纸.pdf'
```

该专项图纸参数用于已诊断的 509 条 SHX 样例；通用四页回归可省略。脚本拒绝使用本机主编辑器目录和正在运行的测试副本，不会结束进程；启动后读取 `output\shx-host-tests.txt` 的 `PASS` 或 `FAIL` 结果。`ShxHostTests.pvp` / `.dll` 仅装进测试副本，正式安装只有前述三个发行文件。

OCR 的纯图片样例为 `tests\ClickCircle_ocr_selection.pdf`，四页分别为 0/90/180/270 度。可运行 `tests\run-ocr-host-tests.ps1 -EditorDirectory 'C:\测试副本\PDF Editor'` 检查宿主渲染、16 个原生/临时旋转组合、重复编号识别、空白区域与批注不变，结果在 `output\ocr-validation\ocr-host-tests.txt`。`obj\stage\OcrTests.exe --live 'C:\验收输出'` 另行验证真实 Windows OCR 和识别中取消；这些实测需要本机 OCR 语言，普通构建测试不调用系统 OCR。

`tools\OcrReviewPreview.cs` 是独立校对窗口的人工验收入口，可引用构建后的 Core 和 WinForms 编译为 GUI 程序，用于检查辅助输入、实时预览及窗口布局，不安装进编辑器。

## 诊断

设置与日志在 `Data\ClickCircle\settings.xml`、`Data\ClickCircle\plugin.log`（找不到便携版根目录时用插件旁的 `ClickCircleData`；`CLICKCIRCLE_DATA_DIR` 仅用于隔离测试）。日志关键行：

- `Hotkey <键> via hook`：钩子装好并启用该快捷键。
- `Hotkey unavailable: <原因>` / `Hotkey cannot be applied: <原因>`：钩子不可用，快捷键停用，原因同时显示在面板状态行。
- `Version <版本>`：本次加载的插件版本，紧邻 `Init OK`，与面板标题显示的是同一个版本号。
- `Picking doc=<ID>`：进入取字状态。
- `Picked <文字> count=<N>`：单击取字成功，`N` 为本次已累积的片段数。
- `BoxPicked count=<N> total=<M> subject=<主题>`：框选取字并入当前主题，`N` 为本次框到几段，`M` 为累积总数。
- `Picking finished count=<N> subject=<主题>`：右键完成取字，进入连续圈注。
- `Stamping finished subject=<主题>`：右键完成本次标注，稍后（约 0.3 秒）把工具交回编辑器。
- `Circle doc=<ID> page=<n> ... subject=<主题>`：放好一个椭圆。
- `OcrReview doc=<ID> page=<n> region=... rotation=...`：仅打开区域识别校对，尚未改主题或画圈。
- `OcrPicked count=<N> subject=<主题>`：已明确确认校对结果并进入连续圈注。
- `OcrDirect doc=<ID> page=<n> region=... rotation=...`：设置里关掉校对窗，区域识别在后台直接跑，不弹窗。
- `OcrDirect empty` / `OcrDirectPicked count=<N> total=<M> subject=<主题>`：直接识别的结果为空（状态提示“未识别到文字”）/ 已把结果直接并入取字或主题并进入圈注。
- `Update check started` / `Update available <tag>`：开始检查更新、发现更新的版本。
- `Update scheduled <tag>`：三个文件已下载并交给替换批处理，编辑器即将关闭重启。
- `Update FAILED <异常>`：检查或下载失败，状态行显示原因，不会关闭编辑器。
